# H.U.G.O. — Personal AI System

Assistente pessoal para Windows com modelo local, conversa natural,
memória persistente e ferramentas.

## Tecnologias previstas
- Python + FastAPI
- Ollama
- SQLite
- React + Tauri
- VS Code e Git

## Estado
Preparação do ambiente. O núcleo de inteligência ainda será implementado.

## Regras de desenvolvimento
1. Implementar por etapas.
2. Testar antes de avançar.
3. Não marcar tarefas como concluídas sem validação.
4. Nunca versionar credenciais ou dados privados.
5. Atualizar a documentação ao final de cada sessão.
